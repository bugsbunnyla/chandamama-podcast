# 🌍 Language-Specific Style Guides
## Cultural Adaptation Standards for 8 Languages

---

## Adaptation Framework

For each language, we apply **5 layers of cultural translation**:

```
Layer 1: Literal Translation (meaning accuracy)
Layer 2: Cultural Localization (references, food, clothing)
Layer 3: Oral Tradition Matching (storytelling style)
Layer 4: Age-Appropriate Vocabulary (complexity grading)
Layer 5: Emotional Resonance (humor, fear, joy calibration)
```

## 🇬🇧 ENGLISH Style Guide

### Vocabulary Tier
```yaml
target_age_4_6:
  sentence_length: "8-12 words max"
  vocabulary: "Common English + 3-5 Indian loanwords per episode"
  loanwords: ["raja", "rani", "mantra", "yoga", "namaste", "chakra", "karma"]
  explanation_style: "Immediate inline explanation"

target_age_7_9:
  sentence_length: "12-18 words"
  vocabulary: "Grade-appropriate + 5-8 Indian cultural terms"
  loanwords: ["dharma", "ashram", "yagna", "guru", "sanyasi", "vedas"]
  explanation_style: "Contextual + glossary at end"

target_age_10_12:
  sentence_length: "18-25 words"
  vocabulary: "Full range + Sanskrit terms with etymology"
  loanwords: ["atman", "brahman", "moksha", "samsara", "ahimsa"]
  explanation_style: "Contextual + cultural notes"
```

### Cultural Bridging
```markdown
- Indian kings → "Raja" (explained as "king") — keep the word
- Indian food → Keep names, describe taste: "sweet laddoos — round, golden sweets"
- Indian clothing → Keep names, describe: "a shimmering saree — a long, beautiful cloth"
- Indian festivals → Explain simply: "Diwali, the festival of lights"
- Sanskrit concepts → Use English equivalents + original: "dharma, which means doing what is right"
```

### Storytelling Voice
```markdown
- Use "Once upon a time in a land called India..." for setting
- Address children as "my little stars", "dear ones", "young travelers"
- Use rhetorical questions: "Can you imagine?", "What do you think happened?"
- Include British-style politeness: "If you please", "kindly", "do you see?"
- Indian warmth: "Just like your grandmother might say..."
```

## 🇮🇳 TELUGU (తెలుగు) Style Guide

### Vocabulary Tier
```yaml
target_age_4_6:
  sentence_length: "6-10 words max"
  vocabulary: "Simple Telugu + Sanskrit tatsama words"
  style: "Rhythmic, repetitive, musical"

target_age_7_9:
  sentence_length: "10-16 words"
  vocabulary: "Standard Telugu + cultural terminology"
  style: "Dramatic, with proverbs (sametalu)"

target_age_10_12:
  sentence_length: "16-22 words"
  vocabulary: "Literary Telugu + Sanskrit scholarly terms"
  style: "Poetic, with classical references"
```

### Cultural Bridging
```markdown
- Kings → "రాజు" (raaju) — natural fit, no explanation needed
- Queens → "రాణి" (raani) — natural fit
- Temples → "గుడి" (gudi) — familiar concept
- Rivers → Compare to Godavari/Krishna: "like our Godavari river"
- Mountains → Compare to Tirumala/Eastern Ghats
- Food → Use Telugu names: "పూర్ణం" (poornam), "పానకం" (panakam)
```

### Storytelling Voice
```markdown
- Open with: "ఒకానొక కాలంలో..." (Once upon a time...)
- Use rhythmic repetition: "అనగా అనగా..." (And so it was...)
- Address children: "బిడ్డలారా" (children), "చిన్నారులారా" (little ones)
- Use Telugu proverbs for morals
- Include Telugu folk song fragments
- Dramatic exclamations: "అయ్యో!" (Oh no!), "అబ్బా!" (Wow!)
```

### Script Sample
```telugu
"బిడ్డలారా, ఈరాత్రి మనం ఒక అద్భుతమైన కథ వినబోతున్నాం. 
ఈ కథ పేరు — [Title]. ఇది పురాతన భారతదేశంలో జరిగింది. 
అప్పటి రాజులు, రాణులు, ఎన్నో మాయలు, ఎన్నో అద్భుతాలు... 
మీరు సిద్ధంగా ఉన్నారా? అయితే వినండి..."
```

## 🇮🇳 HINDI (हिन्दी) Style Guide

### Vocabulary Tier
```yaml
target_age_4_6:
  sentence_length: "6-10 words max"
  vocabulary: "Simple Hindi (tadbhav) + common Sanskrit words"
  style: "Rhythmic, sing-song, repetitive"

target_age_7_9:
  sentence_length: "10-16 words"
  vocabulary: "Standard Hindi + tatsama Sanskrit"
  style: "Dramatic, with dohas and couplets"

target_age_10_12:
  sentence_length: "16-22 words"
  vocabulary: "Literary Hindi + scholarly Sanskrit"
  style: "Poetic, with classical allusions"
```

### Cultural Bridging
```markdown
- Kings → "राजा" — natural, universal concept
- Queens → "रानी" — natural fit
- Sages → "ऋषि" (rishi) — explained as "wise old teacher"
- Forests → Compare to Vindhyas/Himalayas
- Rivers → Compare to Ganga/Yamuna
- Food → Use Hindi names with descriptions
```

### Storytelling Voice
```markdown
- Open with: "एक था राजा, एक थी रानी..." or "बहुत समय पहले की बात है..."
- Address children: "बच्चों", "मेरे प्यारे बच्चों", "छोटे मित्रों"
- Use dohas for morals: "बड़े बड़े ना बोलिए..."
- Dramatic exclamations: "हाय राम!", "वाह!", "अरे!"
- Build tension: "और तब..." (and then...)
- Use alliteration for fun: "कालू कौवा", "मोटू मोर"
```

### Script Sample
```hindi
"बच्चों, आज की कहानी बहुत पुरानी है। 
जब राजा-महाराजा हua करते थे, 
जब जंगलों में जादू हुआ करता था... 
उस समय की यह कहानी है। 
तुम तैयार हो? तो सुनो ध्यान से..."
```

## 🇨🇳 CHINESE (中文) Style Guide

### Vocabulary Tier
```yaml
target_age_4_6:
  sentence_length: "8-12 characters max per clause"
  vocabulary: "Common Mandarin (常用字) + simple Indian terms"
  style: "Simple, rhythmic, with repetition"

target_age_7_9:
  sentence_length: "12-18 characters"
  vocabulary: "Grade-level + cultural terms with explanations"
  style: "Pingshu-style, measured"

target_age_10_12:
  sentence_length: "18-25 characters"
  vocabulary: "Full range + literary terms"
  style: "Classical storytelling with modern accessibility"
```

### Cultural Bridging
```markdown
- Kings → "国王" (guówáng) — familiar concept
- Queens → "王后" (wánghòu) — familiar
- Sages → "智者" (zhìzhě) — wise person, or "仙人" (xiānrén) — immortal sage
- Temples → Compare to Chinese temples: "就像我们的寺庙一样"
- Rivers → Compare to Yangtze/Yellow River
- Mountains → Compare to Tai Shan/Kunlun
- Food → Describe with Chinese equivalents + original names
```

### Storytelling Voice
```markdown
- Open with: "话说从前..." (It is said that long ago...)
- Address children: "小朋友们" (little friends), "孩子们" (children)
- Use "且说" (qiě shuō) to transition
- Dramatic pauses with gavel strikes (醒木)
- Quote classical poetry at emotional peaks
- Use four-character idioms (成语) for descriptions
```

### Script Sample
```chinese
"小朋友们，今晚我要给你们讲一个非常古老的故事。
这个故事来自遥远的印度，来自一本叫《月亮叔叔》的杂志。
很久很久以前，在一个美丽的王国里...
你们准备好了吗？那我们开始吧。"
```
